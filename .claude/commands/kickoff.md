Start a piece of work (new project page, section, or site change).

1. Restate the goal in one line and list the files you'll touch (per `docs/conventions.md`).
2. Read the nearest existing page and match its structure and CSS classes — don't invent new patterns.
3. Flag anything ambiguous or any claim you can't verify (dates, certs, results) and ask before writing.
4. Never put secrets or private details in the site.

Then wait for the user's go-ahead.
